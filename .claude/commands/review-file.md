# ファイルレビュー

**重要: このレビューはTask toolを使って別コンテキストで実行してください。**

対象ファイル: `$ARGUMENTS`

## 実行方法

1. 対象ファイルのパスを確認
2. Task toolを以下の設定で呼び出す:
   - `subagent_type`: "Explore"
   - `prompt`: 下記のレビュー指示とファイルパスを含める

## Task toolに渡すプロンプト

```
以下のファイルをコードレビューしてください: [ファイルパス]

## レビュー観点

### コード品質
- 単一責任の原則: クラス/メソッドは一つの責務のみを持っているか
- 命名: 変数、メソッド、クラス名は明確で意図が伝わるか
- 複雑度: メソッドが長すぎないか、ネストが深すぎないか
- DRY原則: 重複コードはないか

### Ruby/Rails 固有
- イディオム: Ruby らしい書き方か
- Rails規約: Rails Way に従っているか
- マジックナンバー: 定数化すべき値はないか

### ファイルタイプ別チェック

モデルの場合:
- バリデーション、アソシエーション、スコープ、コールバック

コントローラの場合:
- アクションのシンプルさ、Strong Parameters、before_action

テストの場合:
- カバレッジ、エッジケース、独立性

## 出力フォーマット

## ファイル概要
- ファイルパス:
- 責務:
- 行数:

## 発見事項
### 🔴 CRITICAL
### 🟠 IMPORTANT
### 🟡 SUGGESTION
### ✅ 良い点

## 総合評価
[アクションアイテムを含む]
```

## 結果の報告

Task toolからの結果をユーザーにそのまま表示してください。
