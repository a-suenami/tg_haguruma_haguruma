# プルリクエストレビュー

現在のブランチとベースブランチ（デフォルト: main）との差分をレビューしてください。

ベースブランチ: `$1` (指定がない場合は main)

## レビュー手順

1. ブランチ情報を確認
   ```
   git branch --show-current
   git log --oneline main..HEAD  # または指定されたベースブランチ
   ```

2. 差分を取得
   ```
   git diff main...HEAD  # または指定されたベースブランチ
   ```

3. 変更されたファイル一覧を確認
   ```
   git diff --name-only main...HEAD
   ```

4. 各ファイルを詳細にレビュー

## レビュー観点

### 変更の妥当性
- PRの目的に沿った変更か
- 不要な変更が含まれていないか
- 変更の範囲は適切か

### コード品質
- Rails ベストプラクティスに従っているか
- コードは読みやすく保守しやすいか
- 適切なエラーハンドリングがあるか

### テスト
- 新機能/変更に対するテストがあるか
- テストは適切なケースをカバーしているか
- 既存テストへの影響はないか

### パフォーマンス
- N+1 クエリの問題はないか
- 不要なデータベースアクセスはないか
- メモリ使用量に問題はないか

### セキュリティ
- 認証/認可は適切か
- インジェクション脆弱性はないか
- 機密情報の取り扱いは適切か

### データベース
- マイグレーションは適切か
- インデックスは必要か
- 既存データへの影響はないか

### Conventional Commits
- コミットメッセージは規約に従っているか
  - `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`
