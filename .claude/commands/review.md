# コードレビュー

**重要: このレビューはTask toolを使って別コンテキストで実行してください。**

## 実行方法

1. まず `git diff` で変更内容を取得
2. Task toolを以下の設定で呼び出す:
   - `subagent_type`: "Explore"
   - `prompt`: 下記のレビュー指示とdiffの内容を含める

## Task toolに渡すプロンプト

```
現在のブランチの変更をコードレビューしてください。

## レビュー観点

### コード品質
- コードは明確で読みやすいか
- 適切な命名規則が使われているか
- 重複コードはないか
- SOLID原則に従っているか

### Rails ベストプラクティス
- Rails の規約に従っているか
- N+1 クエリの問題はないか
- 適切なバリデーションが設定されているか
- Strong Parameters が正しく使われているか

### テスト
- 新しい機能に対するテストがあるか
- テストは十分なケースをカバーしているか

### セキュリティ
- SQL インジェクションの脆弱性はないか
- XSS の脆弱性はないか
- 認証・認可が適切に実装されているか
- 機密情報がハードコードされていないか

## 出力フォーマット

以下の形式で簡潔にフィードバックを提供:

### 🔴 CRITICAL（重大な問題）
### 🟠 IMPORTANT（重要な問題）
### 🟡 SUGGESTION（提案）
### ✅ 良い点

最後に承認可否を明記。
```

## 結果の報告

Task toolからの結果をユーザーにそのまま表示してください。
